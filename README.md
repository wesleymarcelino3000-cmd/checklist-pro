# Checklist Pro

Aplicação de checklist em tema escuro, preparada para deploy na Vercel com persistência via Vercel Blob.

## Rodar localmente

```bash
npm install
npm run dev
```

## Deploy na Vercel

1. Importe este repositório na Vercel.
2. Crie/conecte um Vercel Blob privado ao projeto.
3. Confirme a variável `BLOB_READ_WRITE_TOKEN`.
4. Faça o deploy.
